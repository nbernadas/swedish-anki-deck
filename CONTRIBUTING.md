# Contributing

Issues and corrections are welcome, especially for Swedish example sentences,
translations, meanings, inflections, frequency rank, and missing audio.

Please do not commit API credentials, downloaded Kelly List source files, Anki
collections, `.apkg` packages, raw JSON cache folders, or generated MP3 files.
Those are intentionally excluded by `.gitignore`.

For a lexical correction, include the Swedish headword, the current content,
the proposed content, and a reliable source where possible. Changes to the
deck's Anki note type should preserve the existing field names whenever
possible: this gives existing users the best chance of updating safely.
