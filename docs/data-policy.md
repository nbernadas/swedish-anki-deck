# Data and publication policy

## What is versioned

- Human-authored code and documentation.
- Small screenshots and examples that illustrate the project.

## What is not versioned

- The Kelly workbook and derived full JSON cache.
- Generated MP3 audio and packaged Anki decks.
- Anki collections, review history, match reports, and personal study data.
- API keys, environment files, and account-specific configuration.

This policy avoids redistributing third-party data without checking its terms,
keeps repository clones manageable, and prevents accidental disclosure of
credentials or learner schedules.

## Responsible use of generated content

Definitions, translations, and examples generated by an LLM are editorial aids,
not authoritative lexicography. Users should report or correct errors rather
than assume that generated content is infallible.
